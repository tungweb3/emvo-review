# EmberEVO（EMBEO）：正式 Ethereum 部署

![EmberEVO 橘色火焰](../web/assets/emberevo-flame-256.png)

正式 Token 已部署：**EmberEVO / EMBEO**，CA **`0x2b82CDEb8477415D541799abB0Cc48044C8ea5f3`**。Ethereum mainnet、18 decimals、10 億枚、原生 ETH 配對。部署交易：[0xd926c03b…63d6aa09](https://etherscan.io/tx/0xd926c03bafe9e92252b37f44a0ea7bf1116f5c8a8cefb2aee7a3d28363d6aa09)。Token 的 Etherscan 原始碼已顯示 Exact Match。

實際 PoolKey fee=12500（1.25%），與歴史 admission manifest 的 3000 分開解讀。初始名義配置 86% 池子、10% Swarm、4% 發幣錢包；4375 個最小單位的取整差額進入發幣錢包。最近核對的一次費用分配已證實 ETH 與 EMBEO 兩種資產及 80/20 分配，不能寫成 ETH-only。

**請勿購買歷史測試 EMVO**：舊 EmberEvo（EMVO）`0x7A427b94547232356cF212Fd1C668e8EB4069a46` 是 Ethereum 主網上的歷史測試發行，不是正式 EMBEO，也不適用正式會員資格。舊合約與池子仍存在；沒有自動換幣或補償承諾。
